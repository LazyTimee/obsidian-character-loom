# Character Loom

[English](README.md) | Русский

Генератор персонажей для настольных ролевых игр в фэнтезийном сеттинге в Obsidian. Создавайте персонажей прямо в заметках и настраивайте таблицы под свой мир.

Интерфейс и начальные таблицы — на русском языке.

## Возможности

- Карточки с именем, фамилией, полом, возрастом, расой, внешностью, характером и предысторией.
- Генерация всей карточки, отдельных разделов или полей.
- Отмена генерации и блокировка карточки от изменений.
- Собственные варианты, веса вероятности и подтаблицы.
- Поиск по вариантам, импорт и экспорт таблиц в JSON.
- Работа в Live Preview и режиме чтения.

## Установка

После публикации плагина в официальном каталоге Obsidian:

1. Откройте **Настройки → Сторонние плагины** и разрешите их использование.
2. Откройте каталог плагинов и найдите **Character Loom**.
3. Нажмите **Установить**.
4. Включите плагин в списке сторонних плагинов.

Обновления устанавливаются через раздел **Сторонние плагины** в настройках Obsidian.

## Быстрый старт

Вставьте в заметку пустой блок:

````markdown
```cloom
```
````

В Live Preview переместите курсор за пределы блока или откройте режим чтения. Плагин создаст и сохранит персонажа в заметке.

Также можно вызвать команду **Character Loom: Вставить генератор после текущего блока** из палитры команд.

### Работа с карточкой

- Нажмите кубик рядом с полем, чтобы получить другой вариант.
- Используйте кнопки разделов для обновления внешности или предыстории и кнопку **Другой персонаж** для полной генерации.
- Кнопка отмены возвращает предыдущий результат генерации.
- Закройте замок, чтобы защитить карточку от редактирования и генерации. Повторное нажатие снимает блокировку.

В Live Preview нажатие на заполненное значение открывает редактор варианта. Можно изменить значение и вес, сохранить или удалить запись из таблицы. Эти действия меняют таблицу и текущую карточку; остальные карточки сохраняют свои значения. В режиме чтения редактор значений недоступен.

В одной заметке можно размещать несколько независимых карточек.

## Настройка таблиц

Откройте **Настройки → Character Loom**, чтобы добавлять, изменять и удалять варианты, создавать подтаблицы и искать записи.

Вес определяет вероятность выбора: варианты с весами `1`, `1`, `2` получают шансы `25%`, `25%`, `50%`. Вес `0` исключает вариант из генерации. Имена, фамилии и возраст можно привязать к полу или разрешить для любого пола.

Импорт и экспорт поддерживают все таблицы сразу или отдельный раздел. Импорт добавляет новые варианты, сохраняя существующие веса; повторный импорт того же файла не создаёт дубликаты.

**Восстановить по умолчанию** заменяет пользовательские таблицы начальными. Перед восстановлением сохраните свои таблицы через экспорт.

## Хранение данных

Персонажи сохраняются в блоках `cloom` внутри заметок. Таблицы хранятся в `data.json` в папке установленного плагина. Плагин работает локально и не выполняет сетевых запросов.

## Разработка

Для сборки нужны Node.js и pnpm. Выполните команды в корне репозитория:

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build
```

Производственная сборка создаёт `main.js`, `manifest.json` и `styles.css` в `release/character-loom/`. Скопируйте эти три файла в `.obsidian/plugins/character-loom/` вашего хранилища. Для автоматического копирования при сборке задайте переменную `CLOOM_PLUGIN_DIR` с путём к этой папке плагина.

Команда `pnpm dev` создаёт `main.js` в корне репозитория для разработки.

Тесты хранятся локально и не включены в репозиторий. При наличии локальных файлов тестов используйте `pnpm test`. Необязательная браузерная проверка запускается через `node scripts/test-settings-browser.mjs` и требует отдельно установленных Playwright и Chromium.

Исходный код находится в `src/`, начальные таблицы — в `src/default-tables.json`.
